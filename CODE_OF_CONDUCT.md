# Code of Conduct

Fluent Blue is a community project. Everyone who participates, in issues, pull requests, discussions or any other project space, agrees to the following.

## Expectations

- Be respectful. Disagree with ideas, not with people.
- Be clear and constructive. Explain the problem you see and, where you can, a way forward.
- Welcome newcomers. Everyone was new once; answer questions with patience.
- Respect decisions. Maintainers decide what is merged; the reasoning will be explained.

## Unacceptable behaviour

- Harassment, insults, discriminatory remarks or personal attacks.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.
- Any conduct that a reasonable person would consider inappropriate in a professional setting.

## Enforcement

Report concerns to the maintainers through a private GitHub security advisory or a direct message to a maintainer. Reports are handled confidentially. Maintainers may remove content, warn, or ban participants who violate this code, in proportion to the behaviour.

## Scope

This code applies to all project spaces and to anyone representing the project in public.
