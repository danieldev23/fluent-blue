# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 - Unreleased

### Added

- Design tokens for color, typography, spacing, radius, elevation and motion.
- Runtime theme engine with light, dark and high-contrast themes, and custom theme registration.
- SVG icon system with theme-aware colors and icon registration.
- Component library: buttons, inputs, selection, navigation, data display, data tables, feedback, layout and advanced components.
- Fluent Blue Design Studio, the interactive showcase application.
- Support for PyQt6 and PySide6 from one code base.
